# 🎬 MovieExplorer

A responsive web application to browse, search, and explore movies and TV shows using the TVMaze API.

## 🚀 Important Links

- **Live Site:** https://movie-explorer-xxx.vercel.app
- **GitHub Profile:** https://github.com/mukty32
- **GitHub Repo:** https://github.com/mukty32/Movie-Explorer

## 🛠️ Tech Stack

- React + Vite
- Tailwind CSS
- TVMaze API

## ✨ Key Features

- **Hero Banner:** Landing page with smooth navigation.
- **Movie Listing:** Responsive grid layout with ratings and dates.
- **Live Search:** Instant search powered by TVMaze API.
- **Details Modal:** Interactive modal popup with movie overview.
